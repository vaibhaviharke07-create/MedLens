# 💊 MedLens

### Scan. Understand. Stay Informed.

MedLens is an AI-powered medicine information assistant that helps users understand information written on medicine labels and prescriptions.

Users can upload an image of a medicine label or prescription. MedLens uses OCR to extract the text and AI to explain the available information in simple language.

---

## 🎯 Problem

Medicine labels and prescriptions can contain difficult medical terms, instructions, warnings, and abbreviations that may be difficult for users to understand.

MedLens aims to make this information easier to understand while keeping the original medical instructions unchanged.

---

## 💡 Solution

MedLens combines:

- 📷 Image Upload
- 🔍 OCR-based Text Extraction
- 🤖 Generative AI
- 🌐 Multilingual Explanation
- ⚠️ Medical Safety Checks

The application extracts readable information from the uploaded image and presents it in a simple, structured format.
